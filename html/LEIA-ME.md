# Versão em HTML — O Sussurro da Chama Antiga

Página única do lançamento do Livro I: o pergaminho “O livro voltou”, a capa e a
sinopse oficial, as ilustrações dos dez primeiros capítulos (com visualização
ampliada) e o Atlas dos Seis Reinos nas duas versões.

- **Abrir no computador:** dê dois cliques em `index.html` (a pasta `assets/`
  precisa ficar ao lado).
- **Publicar de graça:** envie a pasta inteira para GitHub Pages, Netlify ou
  qualquer hospedagem de arquivos estáticos.
- **Atualizar:** não edite à mão — rode `npm run html` na raiz do projeto. A
  página é gerada a partir dos mesmos textos e imagens do site.

Por ser uma página estática, os trechos marcados como spoiler no site não
entram nesta versão.
